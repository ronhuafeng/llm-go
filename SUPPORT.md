# Support

Use GitHub issues for reproducible bugs, provider-neutral feature requests, and
documentation problems.

For security reports, do not open a public issue with sensitive details. Use
GitHub private vulnerability reporting:

https://github.com/ronhuafeng/llmkit-go/security/advisories/new

This project is maintained on a best-effort basis before v1.0.0. Compatibility
and release expectations are documented in `README.md` and `docs/release.md`.
