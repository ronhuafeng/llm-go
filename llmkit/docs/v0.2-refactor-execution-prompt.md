# llmkit-go v0.2 Refactor Execution Prompt

Implement the complete refactor specified by
[v0.2-refactor-plan.md](v0.2-refactor-plan.md) in the current `llmkit-go`
repository.

The referenced plan is authoritative for scope, ownership, target handwritten
API, behavior, migration, and acceptance. Read it completely before editing.

## Rules

- Work only in `llmkit-go`; do not add Codex, provider SDK, or adapter imports.
- Recheck current code and git state. Current source wins for factual baseline;
  the plan wins for target API.
- Treat declarations under `Target Handwritten Public API` as proposed symbols
  to implement, not as APIs that already exist.
- Preserve unrelated and untracked user files.
- Implement detailed paths first and make simple paths exact projections.
- Preserve response and attempt evidence on every partial failure.
- Produce explicit `ValueError` call/decode stages and map them in `llmstep`;
  never infer a stage from response emptiness.
- Apply the settle rule exactly: run error has no output, successful run has an
  output, validation error preserves it, and each failure records its stage.
- Enforce provider name/details equality on every response with typed details.
- Do not add raw metadata maps, provider-neutral streaming, workflow DSLs,
  fluent builders, or syntax-only helpers.
- Do not remove published legacy APIs before the plan's removal version.
- Every public change includes tests, package docs, README, CHANGELOG, release
  notes, migration notes, and the handwritten export allowlist.

## Execution Order

1. Audit current exports and compare them with the target and legacy allowlists.
2. Implement `llmadapter` detailed results and tests.
3. Implement schema-enforced decode and typed violations.
4. Implement evidence-preserving `settle` and `llmstep` detailed paths.
5. Add deprecations, docs, examples, and architecture enforcement.
6. Run the complete requirement audit; do not stop after types compile.

## Validation

Run at minimum:

```sh
GOWORK=off go test ./...
GOWORK=off go vet ./...
```

Also compile the downstream contract block marked
`contract:llmkit-caller` with a fake caller. Confirm no concrete provider appears
in the dependency graph and no unlisted handwritten export remains.

Do not create tags, push, publish releases, or modify another repository unless
the user explicitly authorizes it. If implementation reaches a release gate,
report the exact completed scope, test evidence, remaining legacy exports, and
the tag required by downstream consumers.
