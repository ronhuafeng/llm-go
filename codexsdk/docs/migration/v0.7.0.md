# Migrating to codexsdk v0.7.0

v0.7.0 publishes the generated protocol surface synchronized from
`openai/codex` `rust-v0.150.1`. Handwritten Lifecycle APIs stay the same except
for caller-local `Stream.Next` cancellation.

The classified generated surface is a pre-v1 breaking change relative to
`codexsdk/v0.6.1`.

## Removed stable generated facts

Stop using these generated members. They are no longer in the classified
stable surface:

- `protocolv2.AmazonBedrockCredentialSource` and its `AwsManaged` /
  `CodexManaged` values
- `AccountAmazonBedrock.CredentialSource`
- `AppMetadata.FirstPartyType`
- `HookMetadata.Command`
- `HookMetadata.HandlerType`
- `McpToolCallAppContext.TemplateID`

## Mixed Generated Facades

These types were stable and are now mixed. Existing stable members remain.
New experimental members require experimental runtime opt-in:

- `codexsdk.Accounts`
- `codexsdk.MCPServers`
- `codexsdk.Plugins`
- `protocolv2.ThreadMetadataUpdateParams`

## Additive stable generated facts

v0.7.0 also adds stable generated methods, notifications, and struct members,
including audio `UserInput` variants, MCP event-stream notifications, thread
timeline list responses, and optional `TokenUsageBreakdown.CacheWriteInputTokens`.
Applications may ignore additive members. Recompile against `v0.7.0` before
depending on them.

## Exact Run History Cursor

`Stream.Next` context cancellation now stops only that cursor. It does not
perform Shared Run Cancellation. Call `Close` to terminate the shared Exact
Run for every observer.
