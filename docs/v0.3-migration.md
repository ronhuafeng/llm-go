# Migrating to v0.3

Version 0.3 removes helpers deprecated in v0.2. This is an intentional pre-v1
breaking change: each removed helper duplicated an existing operation or only
changed call syntax.

## Removed API

| Removed symbol | Replacement |
| --- | --- |
| `llmschema.DecodeString[T](text)` | `llmschema.Decode[T]([]byte(text))` |
| `llmadapter.Options[I, O]` | Configure `llmstep.Step[I, O]`, or define an application type implementing `settle.Op[I, O]`. |
| `llmadapter.Op[I, O]` | Use `llmstep.Step[I, O]` for typed calls with validation feedback, or implement `settle.Op[I, O]` for generic stabilization. |
| `llmadapter.NewOp(options)` | Call `llmstep.Run`/`RunDetailed` with a `llmstep.Step`, or pass an application-owned `settle.Op` to `settle.Run`/`RunDetailed`. |
| `llmadapter.ErrNilRender` | For `llmstep`, check `llmstep.ErrNilRender`; application-owned `settle.Op` implementations own their configuration errors. |
| `settle.Bind(op)` | Pass `op` directly to `settle.Run` or `settle.RunDetailed`. |
| `settle.Runner[I, O]` | Call `settle.Run` or `settle.RunDetailed` directly. |

## Examples

Replace syntax-only binding:

```go
// v0.2
output, err := settle.Bind[string, string](op).Run(ctx, input, 3)

// v0.3
output, err := settle.Run(ctx, op, input, 3)
```

Replace the legacy adapter operation with `llmstep` when validation feedback
should participate in later prompts:

```go
output, err := llmstep.Run(ctx, llmstep.Step[Input, Output]{
	Caller:   caller,
	Render:   render,
	Validate: validate,
	MaxIter:  3,
}, input)
```

Use `llmadapter.Value` or `ValueDetailed` directly for a single typed call that
does not need a retry loop.

## Downstream verification

Compile consumers with `GOWORK=off` and no workspace-provided dependency
replacement. Before a v0.3 release, run the repository's clean-consumer check
against the candidate source. Before merging the removal, compile and test a
clean export of caller `main` against that source without a committed `replace`
or `go.work`. Validate real module-tag compatibility during the v0.3 RC and
stable release gates.
