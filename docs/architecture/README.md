# Architecture

The [target design](DESIGN.md) summarizes the accepted repository and migration
model. [Architecture decisions](adr/) record the hard-to-reverse choices, and
the root [context map](../../CONTEXT-MAP.md) links the semantic owners.

These documents govern repository boundaries and migration. Exported code,
module-local API inventories, public behavior tests, module files, and public
Proxy artifacts remain the authoritative owners of their current facts.
