# Require current evidence for retention

Repository material is retained only when a current fact, real consumer,
upstream contract, or indispensable invariant positively requires it.
Historical value alone is not evidence, and tests, validators, data files, or
documents that only consume one another do not create an external owner. When
such a closed evidence loop belongs to a completed transition, its complete
code, test, workflow, data, and documentation closure is removed.

Evidence-backed uncertainty blocks deletion until it is resolved; hypothetical
consumers do not. This supersedes ADR-0016's expectation that completed
proposals, their dedicated isolation check, and one-time root migration
evidence documentation remain; ADR-0008 and ADR-0012's continuing manifest
obligation; ADR-0010's migration-provenance pull-request check; and ADR-0023's
continuing acceptance and archival-evidence obligations. Those decisions
remain as explicit historical records; their unrelated ownership, topology,
and verification rules remain in force.

## Consequences

- Retention has an explicit burden of proof instead of being the default.
- Removing a capability includes its self-justifying tests and documentation.
- Current upstream provenance, published-artifact evidence, migration guides,
  and other facts with live consumers remain under their semantic owners.
